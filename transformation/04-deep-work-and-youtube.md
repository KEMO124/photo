## 8.1 The daily 90-minute block (07:55–09:25, ★★★★★)

It is scheduled **first** because willpower and cognitive control are highest in the first hours after waking, and because a completed deep block by 09:25 makes the whole day a win regardless of what happens after.

### No-phone protocol (non-negotiable)
1. Phone physically in another room *before* the block starts (mere phone presence measurably degrades available cognition — Ward et al., 2017).
2. Laptop: one desktop, one project's windows only. Notifications OS-level off 07:45–09:30.
3. Wi-Fi ON but a site blocker (Cold Turkey / Focus profile) kills social, news, YouTube-as-viewer.
4. Water + coffee on the desk before starting — no legitimate reason to stand up.

### Block structure
| Minutes | Action |
|---|---|
| 0–5 | Read yesterday's shutdown note → write **one sentence**: "This block is successful if ______." |
| 5–50 | Work sprint 1 — the single highest-leverage task |
| 50–55 | Stand, water, look out a window. **No phone.** |
| 55–90 | Work sprint 2 — continue, or second-priority task |
| 90 | 2-min log: what got done, where to resume tomorrow ("open loop note" — makes tomorrow's start frictionless) |

### Focus techniques that actually have evidence
- **Implementation intentions:** decide task *the night before* ("At 07:55 I will implement X"). Doubles follow-through vs deciding in the moment (Gollwitzer meta-analyses).
- **The 10-minute rule:** when the urge to switch hits, note it on paper, give it 10 more minutes. The urge usually dies.
- **Task prioritization:** each night pick tomorrow's **1 deep task + 2 secondary**. Rule: would this matter in 4 weeks? If nothing qualifies, you're choosing tasks too small.

### Idea capture & knowledge management (lightweight on purpose)
- **One inbox:** a single note ("INBOX") in Apple Notes/Notion/Obsidian. Every idea — video topics, code ideas, product thoughts — goes there in one line. Never organize in the moment.
- **Sunday 10′ triage:** inbox → video pipeline / project backlog / delete.
- **Project docs:** every AI project gets one running `NOTES.md` — decisions, dead ends, next steps. Your future self is the main reader.

## 9 — YOUTUBE: the repeatable weekly pipeline

**Cadence: 1 video/week, published Sunday.** Six videos in 49 days. One consistent weekly video beats bursts of three then silence — consistency is what both the algorithm and the habit need.

### 9.1 The weekly assembly line (60 min/day + Sunday batch)

| Day | Daily 60′ block task | Output |
|---|---|---|
| **Mon** | **Research:** pick next topic from idea bank; watch top 3 competing videos at 2×; note their gaps; draft title + thumbnail concept **first** | Validated topic + packaging concept |
| **Tue** | **Write:** full script. Formula: Hook (first 20 s: state the payoff + why care) → deliver in 3–5 chapters → each chapter ends with an open loop → CTA at natural end | Finished script |
| **Wed** | **Film** (rest day = fresh face, no post-gym flush): one take per section, don't restart for small stumbles | Raw footage |
| **Thu** | **Edit pass 1:** rough cut, cut every dead second, structure check | Rough cut |
| **Fri** | **Edit pass 2 + thumbnail:** B-roll/screen recordings, captions, sound; build thumbnail (≤ 4 words, one face or one object, readable at phone size — test at 20 % zoom) | Final video + thumbnail |
| **Sat** | **SEO + package:** title (curiosity + specificity, < 55 chars), description (first 2 lines = mini-hook + keyword), chapters/timestamps, tags, end screen | Upload scheduled |
| **Sun** | **Publish + analytics (batch block):** publish; review last videos: **CTR** (< 4 % = packaging problem) and **retention curve** (cliff in first 30 s = hook problem; steady slope = pacing) — fix exactly one thing next video. Batch 5 title/thumbnail ideas | Live video + one lesson |

### 9.2 Content batching & automation
- **Batch ideas monthly, packaging weekly, filming can be 2 videos in one Wednesday** once comfortable — the highest-ROI batching step (setup/teardown dominates filming time).
- **Templates:** editing project template (intro/outro/captions preset), description template, thumbnail PSD/Canva template with locked fonts/colors → brand consistency for free.
- **Use your own AI skills** (this is your niche advantage): Claude for script first-drafts and title brainstorms (you edit voice), auto-transcription for captions, a prompt library for repeatable research. Document these workflows — *they are themselves video content.*
- **Checklist over memory:** a 10-item publish checklist (title, thumb, description, chapters, tags, end screen, cards, community post, playlist, pin comment). Print it; tick it.

### 9.3 Realistic 49-day YouTube goals
Six published videos with improving CTR/retention and one documented, repeatable pipeline. Subscriber counts are noise at this stage; **packaging skill + retention skill are the assets.** Expect video #6 to be embarrassingly better than video #1 — that's the point.
