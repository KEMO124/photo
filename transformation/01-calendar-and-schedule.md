## 3. Ideal WEEKDAY schedule (hour-by-hour)

*Built for an evening gym session (beats the heat; strength peaks late afternoon). If your work hours differ, keep the blocks and slide them.*

| Time | Block | Purpose |
|---|---|---|
| 06:30 | Wake — feet on floor within 60 s, no phone | Fixed wake time anchors circadian rhythm |
| 06:32 | Weigh-in (after bathroom) → log | Daily data → weekly average |
| 06:35 | 500 ml water + pinch of salt | Rehydrate overnight losses (bigger in Gulf summer) |
| 06:40 | Open curtains, bright light 5–10 min; 10 squats + 10 push-ups | Morning light + movement = alertness, better sleep 16 h later |
| 06:50 | Shower (end 30–60 s cool) → skincare AM (cleanse, moisturize, SPF 50) | Alertness; non-negotiable UV protection |
| 07:05 | Grooming: teeth (2 min, fluoride), tongue scrape, hair, beard edge check | Baseline presentability daily |
| 07:15 | Breakfast + supplements (D3, fish oil, creatine) + coffee #1 | Protein early improves satiety all day |
| 07:40 | Plan review: yesterday's shutdown note → today's 3 priorities | Decide once, execute all day |
| **07:55–09:25** | **DEEP WORK: AI projects (90 min)** — phone in another room | Peak cognitive window; the career block comes *first* |
| 09:25 | Break: 10-min walk (indoors/shade), water | Diffuse-mode consolidation; steps |
| 09:40–12:30 | Work block 2 (job/admin/shallow) — 50/10 cycles | Batched shallow work protects the deep block |
| 12:30 | 10-min walk | Pre-lunch steps |
| 13:00 | Lunch + 500 ml water | Largest protein feed of the day |
| 13:30 | 10-min walk (mall/corridor) | Post-meal glucose control (light activity after meals blunts spikes) |
| 13:45–16:15 | Work block 3 · coffee #2 **before 14:00 only** | Caffeine cutoff ≈ 9 h before bed protects sleep |
| 16:30 | Snack (pre-workout meal) | Carbs + protein 60–90 min pre-lift |
| 16:45–17:45 | **YouTube block (60 min)** — day-specific task (script/film/edit) | Consistent daily pipeline beats weekend binges |
| 17:45 | Change, pack gym bag, electrolytes in water bottle | Zero-friction gym departure |
| **18:00–19:15** | **GYM:** warm-up 10′ → lift 45–55′ → cardio finisher 15–20′ | Full program in `03-training.md` |
| 19:15 | Post-gym stretch 10′ | Hits the day's stretching quota when compliance is highest |
| 19:30 | Dinner | Post-workout protein + carbs |
| 20:00 | Free/social/family time · 15-min walk after dinner if steps < 8k | Life exists; steps top-up |
| 21:30 | Light tasks: idea capture, comment replies, reading 20′ | Low-cognitive wind-down that still compounds |
| 22:15 | **Shutdown ritual:** log food/steps/consistency score → write tomorrow's 3 priorities → phone on charger *outside bedroom* | Closing open loops measurably reduces sleep latency |
| 22:30 | Skincare PM (cleanse → retinol or rest → moisturize) + 5-min stretch (neck/hips) | Retinol at night (photo-degrades in sun) |
| 22:45 | In bed: book (paper/Kindle), AC 21–23 °C, blackout | Cool + dark + regular = the sleep trifecta |
| 23:00 | Lights out | 7.5 h to 06:30 |
